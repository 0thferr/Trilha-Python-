# 🐍 Trilha de Python Básico com Algoritmos, Flask e MySQL

Este repositório contém um plano de estudos de **2 semanas (10 dias úteis)** focado em aprender Python básico, algoritmos, desenvolvimento web com Flask e integração com MySQL.  
O objetivo é desenvolver aplicações em Python de forma consistente, praticando resolução de problemas e boas práticas.

---

## 🎯 Objetivo
Ao final da trilha, você será capaz de:
- Ler e interpretar erros em Python.  
- Desenvolver aplicações básicas com **Flask**.  
- Fazer requisições HTTP com a biblioteca **requests**.  
- Integrar sua aplicação com um banco de dados **MySQL**.  
- Resolver problemas utilizando algoritmos básicos.  

---

## ⏳ Duração
- **Total**: 2 semanas (10 dias úteis)  
- **Carga horária diária**: 8 horas  

---

## 📚 Conteúdo Resumido

### Semana 1 – Fundamentos
- **Dia 1:** Introdução ao Python, variáveis, operadores, entrada/saída.  
- **Dia 2:** Estruturas condicionais e loops.  
- **Dia 3:** Listas e algoritmos básicos.  
- **Dia 4:** Funções e modularização.  
- **Dia 5:** Introdução ao Flask (rotas básicas, Hello World).  

### Semana 2 – Algoritmos e Aplicações Práticas
- **Dia 6:** Strings e requisições HTTP (requests).  
- **Dia 7:** Introdução ao MySQL + integração com Python.  
- **Dia 8:** CRUD (Create/Read) com Flask e MySQL.  
- **Dia 9:** CRUD (Update/Delete) com Flask e MySQL.  
- **Dia 10:** Projeto final – API + Flask + MySQL.  

---

## 🛠️ Tecnologias Utilizadas
- **Python 3**  
- **Flask**  
- **Requests (HTTP)**  
- **MySQL** (via `mysql-connector-python`)  
- **Replit** (ambiente online sugerido para prática)

## ✅ Conclusão
Esta trilha oferece uma base sólida para quem deseja:  
- Entrar no mundo da programação com Python.  
- Praticar **algoritmos e resolução de problemas**.  
- Criar aplicações **Full-Stack simples** (Flask + MySQL).  
- Evoluir para projetos mais avançados em **back-end e APIs**.
